### Selected work

**SenticLens** · first-author paper, SENTIRE Workshop at IEEE ICDM 2026
A production sentiment-analysis framework that audits whether LLM outputs stay consistent, and flags inconsistent ones before they reach downstream analytics. [Labcast talk](https://youtu.be/WWc0BVTbDmk)

**Kenza Living** · Technical Project Lead (part-time)
Bilingual (English/Arabic) community platform, live on the App Store, Google Play and the web (React Native, Node.js, PostgreSQL on AWS). Its LLM assistant turns residents' messages into bookings and service tickets, with server-side guardrails for security and correct bookings.

**[Agentbox](https://github.com/savannahfeder/agentbox)** · open-source contributor
A desktop app that runs many Claude Code and Codex agents in parallel, each in its own git worktree. First contributor to bring Windows support, merged upstream.

**[RAG grounding audit](https://github.com/simer05/rag-grounding-audit)**
Tested 3 open-weight LLMs on 500 HotpotQA questions: reordering the same passages flipped 8–14% of answers, and models answered without evidence 26–40% of the time.

**TabM++** · extended the TabM-PLR tabular deep-learning baseline; improved the matched baseline on all 5 TabReD datasets.

**Hardware-aware U-Net for Stable Diffusion** · 55% activation sparsity, 24% lower memory, 12.6% faster inference.

**CodeLah!** · LoRA-fine-tuned CodeGen-350M for code ↔ natural-language translation (+40.8% over baseline).
